# Robotics Course — Sample Videos

## Overview
A collection of sample videos and demonstrations related to robotics and mechanical-system simulation. The repository is intended as an educational reference and record of practical course material.

## Topics
- Robotics fundamentals
- Mechanical-system simulation
- Multibody dynamics
- MSC Adams demonstrations
- Practical engineering examples

## Software
- MSC Adams
- Related robotics and engineering simulation tools

## Repository Contents
The repository contains recorded course and demonstration videos, including introductory material, session recordings, and an Adams-related example.

## Purpose
This repository serves as an educational archive for robotics and engineering simulation examples. It can be useful for students and engineers reviewing practical modeling and simulation concepts.

## Notes
The collection may be expanded with written tutorials, model files, exercises, references, and structured descriptions for each video.
